# AWS Certified Cloud Practitioner (CLF-C02)
 
Documentation repository for the AWS Certified Cloud Practitioner exam.
 
---
 
## About this repository
 
This repository documents my learning process for the CLF-C02 exam. Each folder contains notes written in my own words, hands-on lab summaries, and key concepts for each exam domain.

## Study approach
 
Each concept follows three steps:
 
**One — Understand the why.** What problem does this service solve? Why does it exist?
 
**Two — Touch it.** Open the AWS console and use the service. Stay within free tier.
 
**Three — Document it.** Write what I learned in my own words before moving on.
